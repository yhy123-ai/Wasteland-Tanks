# 钢铁荒原 · Wasteland Tanks

一个基于 HTML Canvas 的坦克生存肉鸽游戏：驾驶战车突破围攻，在随机升级中形成火力组合，并挑战十分钟后的双 Boss。

**[在线体验](https://iron-wasteland-tanks.nimble-ibex-6140.chatgpt.site)** · **[另一个作品：十点晨报](https://github.com/yhy123-ai/10-AM-Briefing)**

## 项目出发点

围绕短时游玩的完整体验，连接“选择战车 → 战斗与拾取 → 随机升级 → 挑战精英 → 终局与车库成长”。玩家可以在不同战车与强化选择之间尝试不同构筑。

该项目展示浏览器交互设计、战斗状态管理、Canvas 实时绘制和本地成长存储。

## 核心内容

| 模块 | 内容 |
| --- | --- |
| 战车选择 | 游骑兵的连射主炮、棱镜的贯穿激光、重锤的高爆榴弹 |
| 战斗操作 | 键盘移动、鼠标瞄准与开炮、突进及暂停 |
| 成长构筑 | 拾取经验、升级三选一、武器与组合进化 |
| 关卡节奏 | 四轮精英战、逐步提升的敌人压力与十分钟终局 |
| 终局挑战 | 双 Boss 交战 |
| 车库成长 | 局外升级与本机进度保存 |
| 战场反馈 | 装甲、护盾、经验、武器配置、时间、歼敌数与雷达 |

## 快速开始

1. 打开在线体验，或在本地打开 `out/index.html`。
2. 选择一种战车，点击“驶入战场”。
3. 移动、瞄准并收集经验，在升级时选择强化。
4. 应对精英战，准备终局 Boss 挑战。

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 瞄准与开炮 | 鼠标 |
| 突进 | Space |
| 暂停 | Esc |
| 选择升级 | 1 / 2 / 3 |

推荐使用有键盘与鼠标的桌面浏览器。当前操作设计以桌面设备为主。

## 技术与实现

- **HTML / CSS**：菜单、HUD、升级选择与结算界面。
- **原生 JavaScript**：输入、战斗、升级和游戏状态切换。
- **Canvas 2D**：战场、战车、敌人、弹道与战斗效果绘制。
- **localStorage**：保存本机进度；清除浏览器站点数据会影响存档。
- **纯静态托管**：无外部脚本依赖，无需账号或后端服务器。

核心实现集中在单个 HTML 文件中，便于直接运行和阅读。随着玩法增加，可继续拆分渲染、战斗、成长与存档模块，以改善维护体验。

## 本地运行与托管

不需要安装依赖或执行构建。直接用现代浏览器打开 `out/index.html` 即可。

如需通过本地 HTTP 服务访问：

```sh
python -m http.server 8080 --directory out
```

然后访问 `http://localhost:8080`。发布到静态托管服务时，将 `out/` 设置为站点目录即可。原 Sites 项目 ID 仅用于保留来源，复制到自己的托管项目时应使用自己的项目配置。

## 手动验收清单

- 三种战车均能开始游戏，初始武器表现符合选择。
- 移动、瞄准、开炮、突进与暂停能够正常响应。
- 升级选择期间战斗暂停，选择后恢复。
- 装甲、经验、击杀数和时间等反馈随战斗更新。
- 局外成长可在刷新后读取，结算后可重新开始。

这份清单用于复核当前版本，不代表全部流程已在每种设备与浏览器上完成验证。

## 当前边界与后续方向
